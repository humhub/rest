Soft deletes an user by id

Soft deletes the user (profile data and memberships are removed, the user's own content is kept).

Spaces owned by the user are transferred to the API user who performs the request, unless deleteSpaces=1 is given. Warning: with deleteSpaces=1 the owned spaces are deleted irrevocably, including the content of other users.

path Parameters
id
required
integer

The id of user

query Parameters
deleteSpaces
integer
Default: 0
Enum: 0 1

How to handle the spaces owned by the user:

  • 0 (default): the ownership of each owned space is transferred to the API user who performs the request.
  • 1: the owned spaces are deleted irrevocably, including all memberships and all content and files of other users in these spaces.

Responses

/api/v1/user/{id}

Hard deletes an user by id

Deletes the user completely, including the user's own content.

Spaces owned by the user are transferred to the API user who performs the request, unless deleteSpaces=1 is given. Warning: with deleteSpaces=1 the owned spaces are deleted irrevocably, including the content of other users.

path Parameters
id
required
integer

The id of user

query Parameters
deleteSpaces
integer
Default: 0
Enum: 0 1

How to handle the spaces owned by the user:

  • 0 (default): the ownership of each owned space is transferred to the API user who performs the request.
  • 1: the owned spaces are deleted irrevocably, including all memberships and all content and files of other users in these spaces.

Responses

/api/v1/user/full/{id}
